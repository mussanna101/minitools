## How to use this file

1. Open **Google Search Console** > **URL Inspection**.
2. Paste a URL below, press Enter, wait for the check, then click **Request Indexing**.
3. Start with the homepage, all 8 category pages, then the highest-value tools. Submit the rest in small batches over a few days.
4. In GSC > **Sitemaps**, submit `sitemap.xml` once (it already contains all 97 URLs).

> Important: do **not** resubmit the same URL over and over. One request per URL, then let Google crawl on its own schedule.

## 4. Bing Webmaster Tools + IndexNow (fast indexing for Bing/DuckDuckGo)

The site already exposes an IndexNow key file and a submission script:

- **Key file:** `https://minitools-silk.vercel.app/80895b70cacd3fb9303a4f4a1c82d51c.txt`
- **Host:** `minitools-silk.vercel.app`
- **Script:** `node scripts/submit-indexnow.mjs` (send homepage + all category + all tool URLs)

### Setup

1. Open **https://www.bing.com/webmasters** and add the site (or import from Google Search Console).
2. Verify ownership using one of these (the key file is already deployed, so the DNS/HTML-meta options are easiest):
   - **Bing meta tag**: copy the verification meta tag Bing gives you and add it to the site head (or index.html).
   - **XML file / DNS TXT**: follow whatever Bing offers in the verification panel.
3. After verification, run: `node scripts/submit-indexnow.mjs` from the repo root.
   - Expected output: `IndexNow HTTP 202 — <N> URLs submitted` (202 = accepted).
4. IndexNow is manual on purpose so it is not spammed on every build. Re-run it after a content release or when you add tools.

### Notes

- IndexNow only signals Bing / DuckDuckGo / others that support it — **Google ignores IndexNow** (use **Request Indexing** in Google Search Console instead).
- If Bing returns 403, re-verify ownership and confirm the key file URL returns `200 text/plain` with the exact key string.
